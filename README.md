# Retail Business Intelligence & Profitability Analysis Using Python

## Project Overview
This project analyzes retail sales data to understand business performance, profitability, customer activity, product performance, and regional sales trends.

The analysis was performed using Python in Google Colab.

## Project Objectives
- Analyze retail sales and profit.
- Clean and prepare the dataset.
- Calculate total sales, total profit, and profit margin.
- Compare category-wise and region-wise performance.
- Analyze monthly sales trends.
- Identify the top 10 products by sales and profit.
- Export the cleaned dataset for further analysis.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- Matplotlib

## Dataset Information
- Dataset: Sample Superstore
- Original Records: 9,994 rows
- Original Columns: 21
- Cleaned Columns: 22

## Key Performance Results

| Metric | Result |
|---|---:|
| Total Sales | $2,297,200.86 |
| Total Profit | $286,397.02 |
| Total Orders | 5,009 |
| Total Customers | 793 |
| Profit Margin | 12.47% |

## Analysis Performed
1. Data loading and inspection.
2. Missing value and duplicate checks.
3. Date conversion and data preparation.
4. Sales and profit calculations.
5. Category-wise analysis.
6. Region-wise analysis.
7. Monthly sales trend analysis.
8. Top 10 products by sales.
9. Top 10 products by profit.
10. Data visualization using charts.

## Key Findings
- Technology was the highest-performing category by sales and profit.
- The West region recorded the highest sales.
- November 2017 had the highest monthly sales.
- Canon imageCLASS 2200 Advanced Copier ranked highest in both sales and profit.

This project demonstrates how Python can be used to clean, analyze, and visualize retail business data. The findings provide useful insights into sales performance, profitability, products, and regional trends.
